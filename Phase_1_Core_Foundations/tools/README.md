# Phase 1 Security Automation & AI Tools

Following the **Manual First → Automate Second → Break & Fix** rule, reusable scripts and portfolio tools are built here *after* completing each manual lab:

- **Week 1:** `suid_cap_scanner.py` *(Coming after Lab 1A manual completion)* — Enumerates SUID/SGID binaries and Linux file capabilities, flagging GTFOBins/high-risk vectors.
- **Week 2:** `linux_hardening_auditor.py`
- **Week 3:** `pcap_triage_extractor.py`
- **Week 5–6:** `crypto_vault_cli.py`, `crypto_jwt_auditor.py`
- **Week 7–8 (Capstone #1):** `ai-secops-pcap-log-analyzer`
