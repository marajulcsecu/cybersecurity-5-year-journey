# Phase 1 Lab Writeups & Feynman Proofs

Keep your **own** hands-on verification outputs and 3–5 line Feynman summaries here as you complete each lab.

## Recommended Writeup Template (`weekX_labY_writeup.md`)
1. **Target & Goal:** What vulnerability or forensic scenario did you investigate?
2. **Manual Discovery:** Exact enumeration commands you ran by hand (`find`, `getcap`, `tshark`, etc.).
3. **Exploitation / Analysis Proof:** Command outputs (flags/UIDs/timelines) — never commit real host keys or secrets!
4. **Remediation & Verification:** Exact fix applied and proof that the exploit no longer works.
5. **Feynman Check (3–5 lines):** Explain *why* the flaw worked at the OS/protocol level as if teaching a peer.
