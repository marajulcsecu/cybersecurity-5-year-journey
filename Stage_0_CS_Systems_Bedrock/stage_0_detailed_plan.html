Why Start at Stage 0?

  • University courses teach C/COA/OS for exams—not how bugs emerge in real binaries and kernels.
  • Mastering Stage 0 removes every "black box" before Stage 1 (OS), Stage 2 (Net), and Stage 5 (Binary RE).

The 5-Step Mastery Loop

  • 1. Visual HTML Lecture → 2. Bangla Q&A → 3. Build & Break Lab (GCC/GDB/Docker) → 4. Fix & Verify → 5. Feynman Writeup.
  • Zero LLM-wrapper distractions—pure C, Bash, Python, and primary Linux tools.

Lightweight Local Toolchain

  • Zero heavy VMs: native Linux / tiny Docker lab with gcc, gdb, readelf, objdump, strace, ltrace.
  • Runs comfortably in < 30 MB RAM on your existing laptop.
